# Original Suba Useful Archive

This folder preserves useful material from the earlier `suba` project so the new cleaned project has the old workflow history in one place.

## Contents

- `original_pdf.pdf`: original scanned source PDF used for OCR/provenance.
- `legacy_scripts/`: older OCR, chapter detection, translation, and PDF-building scripts.
- `chapters/`: older detected chapter index JSON files.
- `ocr_pages/`: original English OCR page text files before the newer cleanup pass.
- `old_zh_pages/`: older page-by-page Chinese outputs from the previous workflow.
- `old_pdfs/`: older generated PDF outputs.

## Notes

The old `pages_bad_20260406-215743` backup, `.DS_Store` files, and temporary chunk PDFs were intentionally not copied because they were clutter or known-bad intermediate outputs.

The current cleaned/translated workflow lives in the main project folders: `clean_pages`, `translation`, `scripts`, and the final PDFs at the project root.
